# `hyperformula-ui/` — UI components

A folder of npm workspaces, not a package: the published `hyperformula-ui` package in `packages/core/`, an editor-only demo in `demo/`, and a Playwright suite in `e2e/`.

- How the UI works, its own code style, its tests and its release: [`dev-docs/README.md`](dev-docs/README.md)
- Repository-wide standards: [`../dev-docs/README.md`](../dev-docs/README.md)

The code style here is not the engine's. Read [`dev-docs/CODE-STYLE.md`](dev-docs/CODE-STYLE.md) before editing.

Skill: `hyperformula-ui-dev`.
