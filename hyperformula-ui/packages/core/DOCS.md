## Examples

### `FormulaBuilder`

Master class wiring the formula-editing experience onto one grid instance: owns the popup context, the error popup, and the single shared `FormulaEditor`, and optionally hosts a `FormulaBar`.

```ts
const builder = new FormulaBuilder({
  rootEl: gridRoot,
  adapter: new MyGridAdapter(grid),
  hyperformula: hf,
  formulaBarContainer: "#formula-bar",
});
builder.openEditor(cellMount, "=SUM(A1:B2)");
```

### `IGridAdapter`

The contract between the engine-agnostic editor core and a host grid.

```ts
class MyGridAdapter extends NullAdapter {
  getActiveCell() {
    return this.grid.selection ?? null;
  }
}

const builder = new FormulaBuilder({ rootEl: gridRoot, adapter: new MyGridAdapter() });
```

### `NullAdapter`

No-op `IGridAdapter` implementation — the fallback `FormulaBuilder` uses when constructed without an adapter, and the base class for basic adapters.

```ts
class MyAdapter extends NullAdapter {
  getActiveCell() {
    return this.host.selection;
  }
}
```

### `FormulaBar`

Excel-style formula bar composing `FormulaBarAddressBox` and `FormulaBarCell`.

```ts
const builder = new FormulaBuilder({ rootEl: gridRoot, adapter, formulaBarContainer: barEl });
```
