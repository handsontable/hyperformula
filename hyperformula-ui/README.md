# `hyperformula-ui/`

Reserved for the HyperFormula UI components: reference highlighting, the inline formula editor, and function help.

The UI is not here yet. It is imported from the formula-builder repository in a separate change, nested: the whole repository moves into this directory with its layout and history intact, so this directory will hold a group of packages rather than a single one. Until then it holds only this file, and nothing from it is listed in the root `workspaces` array.

The planned layout, and everything the import has to do: [`dev-docs/STRUCTURE.md`](../dev-docs/STRUCTURE.md#what-the-move-still-owes).
