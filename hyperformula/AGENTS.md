# `hyperformula/` — the calculation engine

The published `hyperformula` package: the parser, the interpreter, the dependency graph, and every built-in function. TypeScript, headless, no DOM.

- How the engine works, how it is built and tested: [`dev-docs/README.md`](../dev-docs/README.md)
- Repository-wide standards — what a change must include, style, testing, pull requests: [`../dev-docs/README.md`](../dev-docs/README.md)

Run package scripts from this directory, or from the repository root with `--workspace=hyperformula`.

Skill: `hyperformula-dev`.
