# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues, discussions or pull requests.

Email [security@handsontable.com](mailto:security@handsontable.com) instead. Include:

- the HyperFormula version you used
- steps to reproduce the problem, or a proof of concept
- the impact you expect, for example what an attacker could read or change

We confirm that we received your report and keep you updated while we work on a fix. We publish the details only after a fixed version is released.

## Supported versions

Security fixes ship in a new release of HyperFormula. Use the [latest version](https://www.npmjs.com/package/hyperformula) to get them.
